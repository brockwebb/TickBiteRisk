# Source Materials — Reporting-Basis Adjustment Identification

This directory holds the external source materials and verification artifacts
behind the identification decision documented in
`docs/research/lab-notes/08-reporting-basis-identification.md`. These are kept in
the repo (not in a local Downloads folder) so the methodology and discussion
sections cite retained, reproducible files.

## Files

- `did-control-verification-2017-2019.csv` — Verification artifact generated by
  directly downloading the CDC 2008-2021 county-FIPS Lyme dataset (resource
  `qtbi-xd4i`) and counting, per candidate state, how many distinct county FIPS
  codes resolve (are not suppressed) across the 2017-2019 pre-window. This is the
  empirical basis for the finding that no out-of-region DiD control panel is
  estimable. Best candidate resolves 3 counties over 3 years; parallel-trends
  cannot be fit on that.

- `county-level-lyme-availability-2026-05.md` — EXPECTED, drop in manually.
  The external research assessment (Perplexity, May 2026) of county-level Lyme
  case-data availability and state-DOH data-request procedures for the ten
  candidate low-incidence states. Move the file from the local Downloads copy
  ("County-Level Lyme Disease Case Data Availability, Sources, and Data Request
  Procedures for Ten Low-Incidence States.md") into this directory under this
  name. Treat it as an unverified secondary source: its dataset-existence claims
  for `qtbi-xd4i` and `x5j9-wybp` were independently verified live; its per-state
  state-DOH procedure details were NOT independently verified and should be
  re-checked before any are acted upon.

## Provenance notes

- CDC 2008-2021 (qtbi-xd4i) and 2022-2023 (x5j9-wybp) were confirmed to resolve
  live as of 2026-05-31. The 2022-2023 series is also mirrored on the Data Rescue
  Project portal; the CDC origin resolves, and the mirror reflects independent
  archival of the same federal series.
- The multi-year aggregate XLSX products (2016-2019, 2019-2022) are
  presence/absence maps (one multi-year total per county), not annual panel data,
  and are unusable for a parallel-trends test.
